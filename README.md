# Plant-Care-Scheduler
To build a system that helps users track and manage the care schedule of their indoor plants, including watering, fertilizing, and sunlight needs, while maintaining logs and reminders.

# ✅ Project Overview
Frontend: React (Vite or CRA)

Backend: Node.js + Express

Database: MySQL

# Frontend (React)
Build a simple UI for adding and viewing plants.

Track care tasks (watering, fertilizing, sunlight).

Provide alerts and care logs.

# Backend (Node + SQL)
Set up a database to store plant info, care logs, and user preferences.

Create API routes for handling plant data.
